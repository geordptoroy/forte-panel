## Lacunas deliberadamente abertas

- O canvas visual **não é prova de uma capability operacional**.
- O enum legado de capabilities da plataforma permanece compatível até existir migração completa.
- A PAPI não é provider do produto; referências a ela pertencem apenas a revisão de engenharia.
- Nenhuma spec autoriza emparelhamento, limpeza de sessão ou envio para WhatsApp real sem autorização específica e número de teste dedicado.

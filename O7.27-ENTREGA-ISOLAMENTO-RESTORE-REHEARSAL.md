# O7.27 — Isolamento, readiness e rollback do restore rehearsal

**Data:** 2026-09-30  
**Estado:** concluído em código e testes locais; nenhuma aprovação de staging foi emitida.

Foi criado o comando:

```bash
pnpm check:restore-rehearsal-isolation EVIDENCE.json
```

O gate verifica sete condições antes de considerar o ambiente isolado:

- `CORE_ONLY_MODE=true`;
- tráfego bloqueado;
- outbound desativado;
- todos os endpoints válidos e fora da lista de hosts de produção;
- diretório de sessão restaurado diferente do diretório ativo;
- rollback preparado;
- readiness aprovada.

A decisão é `approved`, `inconclusive` ou `blocked`. Endpoint produtivo, outbound ligado, reutilização do diretório ativo, rollback não preparado ou readiness falha produzem bloqueio. Readiness desconhecida produz inconclusão quando as demais condições estão seguras.

O script não faz chamadas de rede, não altera ambiente, não inicia serviços e não executa rollback. Ele apenas avalia um JSON de evidências fornecido pelo operador.
